ABOUT THIS PROJECT

이 작은 실험실에서
무엇을 배우나요?

로봇암의 가상 모델을 웹서비스로 제공하는 지능형 IoT 플랫폼 과제입니다. 로봇의 동작 원리를 체험하고, 같은 서비스를 컨테이너로 재현하는 과정을 함께 다룹니다.

01 / MODEL

관절에서 위치로

슬라이더로 관절을 움직여 보세요. 각도 변화가 집게의 X·Y·Z 좌표로 어떻게 이어지는지 확인할 수 있습니다.

02 / INTERACT

목표에서 움직임으로

집게를 끌거나 목표를 선택하면 역기구학으로 가능한 자세를 찾습니다. 닿을 수 없는 위치에는 이유를 안내합니다.

03 / DEPLOY

가상 모델을 웹서비스로

OpenShift의 Deployment·Service·Route로 제공하고, 두 ConfigMap으로 화면과 모델 설정을 분리합니다. Probe는 서버 상태를 확인합니다.
